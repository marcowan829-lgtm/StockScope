# StockScope｜美股研究工作台 V3（实时看盘优先）

这是一个用于课程项目和个人学习的 Streamlit 交互式美股仪表盘。本版本把**实时看盘尝试功能**作为默认首页；原有日线市场首页、筛选器和历史风险分析继续保留。

## V3 新增：实时看盘（默认打开）

- 选择内置股票代码，默认 NVDA。
- 选择 1 分钟、5 分钟、15 分钟、30 分钟或 60 分钟 K 线。
- 查看分钟蜡烛图、每根 K 线的成交量、最新返回价格，以及相对上一根 K 线的变化。
- 支持包含盘前/盘后数据的选项。
- 支持手动刷新、每 15 秒、每 30 秒或每 60 秒重新请求数据。
- 查看最多 6 只自选股的最新返回分钟 K 线时间、价格、成交量和时间戳差值。
- 可以下载所选股票最近返回的分钟数据 CSV。
- 会根据最后一条 K 线的时间戳显示“接近当前时间”或“数据可能较旧”等提示。

**重要：这不是经过交易所认证的实时行情服务。** 刷新频率表示应用重新请求的频率，不代表数据保证实时或固定延迟 15 分钟。`yfinance` 是第三方工具，Yahoo 行情可能延迟、缺失、被限制或不可用。时间戳差值不是实际数据传输延迟。不要将其用于交易执行或作为唯一投资决策依据。

## 历史分析功能

侧边栏的“市场首页”“市场概览”“股票筛选器”“收益与风险”“个股详情”“方法与数据”保留了上一版本功能，包括指数快照、最近交易日涨跌榜、成交量榜、收益—风险散点图、股价与成交量图，以及可选基本面字段。

实时看盘默认只请求分钟行情，不会先等待全量股票日线数据加载；进入历史分析页面后才下载/读取日线数据。

## Windows 启动

1. 下载 ZIP 并完整解压到一个简单路径，例如 `C:\Users\Lenovo\Desktop\stockscope_dashboard`。
2. 确认文件夹内有 `app.py`、`requirements.txt`、`start_windows.bat`。
3. 双击 `start_windows.bat`。第一次运行会联网安装依赖。
4. 成功启动后，黑色窗口会显示 `Local URL`，通常是 `http://localhost:8501`。如果浏览器没自动打开，请把该地址复制到浏览器。
5. 不要关闭运行中的黑色窗口；关闭窗口会停止网页。

## 下周美股开盘时如何测试

1. 打开 StockScope，默认进入侧边栏的“实时看盘”。
2. 选择 `NVDA`，K 线周期选“1 分钟”，勾选“包含盘前/盘后”，自动刷新先选“每 30 秒”。
3. 在美东常规交易时段（通常周一至周五 9:30–16:00，节假日除外）观察“最新 K 线时间”和自选股表格。也可以在盘前/盘后观察，但可用性会因 Yahoo 数据而异。
4. 等 1–2 分钟，确认最新 K 线时间是否向前推进、价格或成交量是否变化。
5. 若无数据或时间戳不更新，将页面显示内容和黑色窗口报错截图发给开发者。也可运行 `测试分钟行情.bat` 单独测试 Yahoo 的分钟数据接口。

程序显示的交易时段只是按美东星期与时间粗略估算，不会核对美股交易所节假日。

## 独立测试行情接口

双击 `测试分钟行情.bat`，它会依次尝试获取 NVDA（美股分钟数据）和 BTC-USD（全天候交易资产）的最近分钟数据，打印当前 UTC/美东时间、最新 K 线时间戳和时间差。测试程序会保留命令窗口以便查看结果。周末 NVDA 的数据停在最近一个交易日是正常情况；BTC-USD 用于辅助检查请求是否通畅，不代表美股数据延迟相同。

## 如果窗口闪退或网页打不开

在项目文件夹地址栏输入 `cmd` 并回车，然后运行：

```bat
python --version
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

如果有报错，不要关闭黑色窗口，复制最后 20–40 行信息。

## 数据方法与限制

- 内置约 50 个美股与市场 ETF 代码，不是全市场名录。
- 历史价格使用 `auto_adjust=True` 的日线数据；实时 K 线请求使用 `auto_adjust=False` 读取 Open/High/Low/Close/Volume。
- 一分钟数据可用历史范围有限，接口会根据标的、市场时段及数据源规则变化。
- 自选股列表暂存在 Streamlit 会话中，应用重启后可能重置。
- 此项目是课程/学习原型，不是交易系统，不构成投资建议。
- `yfinance` 能获取数据不等于取得公开再分发行情的授权。公开部署前需要核实 Yahoo Finance 适用条款，并向课程教师确认是否符合“开放 API / 可验证开放数据集”的要求。
